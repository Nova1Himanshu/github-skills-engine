# GitHub Skills Engine

A repo-first starter system for collecting, reviewing, versioning, and distributing reusable AI skills from GitHub repositories.

## What it does
- Reads curated public GitHub repositories from `config/sources.json`.
- Discovers `SKILL.md` files and selected documentation.
- Imports existing skills and creates review drafts from README/docs.
- Generates a manifest and sync report.
- Supports local execution and scheduled GitHub Actions.
- Never executes imported scripts.

## Quick start (Windows PowerShell)

Install Python 3.11+, clone this repository, then run:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python scripts/sync_repositories.py
```

## Automated sync
The workflow in `.github/workflows/sync-skills.yml` runs weekly and can be triggered manually. It prepares a pull request with discovered source material. Review every change before merging.

## Manual skill generation with ChatGPT Plus (no API credits)

The discovery workflow also creates prompt packets from selected source drafts in `library/manual-generation/`. This step is offline and makes no AI API calls.

1. Open **Actions → Prepare ChatGPT skill packets → Run workflow**, or run **Sync skills** to prepare packets as part of source discovery.
2. Review and merge the pull request generated by GitHub Actions.
3. Open a packet file in `library/manual-generation/` and copy its complete contents into a new ChatGPT Plus conversation.
4. Review the resulting `SKILL.md` for correctness, source attribution, safety, and license compatibility.
5. Manually add the approved skill to `library/curated/<skill-name>/SKILL.md` and commit it.

This requires manual copy/paste into ChatGPT. ChatGPT Plus does not automatically read generated prompt packets or write its answers back to GitHub. No OpenAI API key, API credits, or API billing are required for packet preparation.

The paid API generator was retired from the default workflow to avoid accidental API calls.

## Safety
This pipeline does not retrain ChatGPT, does not automatically install skills into ChatGPT, and does not execute source repository scripts. Review licenses, attribution, security, and instructions before promoting imported material to `library/curated/`.
