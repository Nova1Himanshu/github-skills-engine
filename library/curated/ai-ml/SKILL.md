# AI/ML

1. Define task, baseline, evaluation metric, data constraints, and deployment environment.
2. Check data provenance, permissions, quality, leakage, imbalance, and representativeness.
3. Establish a simple baseline before choosing a complex model.
4. Separate training, validation, and test data correctly.
5. Track configuration, dependencies, random seeds, metrics, and versions.
6. Evaluate failure modes, robustness, latency, cost, privacy, and misuse risks.
7. Never fabricate benchmark results; run experiments or label estimates clearly.
8. Document reproducibility steps and limitations.
