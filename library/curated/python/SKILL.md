# Python

1. Inspect Python version, dependency manager, repository structure, and conventions.
2. Prefer clear functions, type hints where useful, and explicit error handling.
3. Use virtual environments and appropriate bounded or pinned dependencies.
4. Avoid shell injection, unsafe deserialization, hard-coded secrets, and swallowed exceptions.
5. Separate configuration from code; validate external input.
6. Add tests for behavior and edge cases; mock external services.
7. Run formatter, linter, type checker, and tests if configured.
8. Provide reproducible setup and execution commands.
