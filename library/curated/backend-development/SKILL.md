# Backend Development

1. Inspect runtime, framework, database, deployment target, and architecture.
2. Define API contracts, validation rules, error behavior, and authorization boundaries.
3. Validate all untrusted input server-side.
4. Use parameterized queries or safe ORM patterns; avoid string-built SQL.
5. Keep secrets in environment/secret managers, never source control.
6. Apply least privilege, safe logging, rate limiting where appropriate, and clear errors.
7. Consider migrations, transactions, retries, idempotency, and observability.
8. Test happy paths, invalid input, authorization failures, and edge cases.
9. Run available tests and state what remains unverified.
