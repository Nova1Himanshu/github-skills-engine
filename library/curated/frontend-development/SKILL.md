# Frontend Development

1. Inspect the repository, package manager, scripts, framework version, and existing conventions.
2. Restate expected behavior and acceptance criteria.
3. Plan the smallest maintainable implementation.
4. Reuse existing components and patterns before adding dependencies.
5. Handle loading, empty, error, success, and disabled states.
6. Keep accessibility, responsive behavior, type safety, and performance in scope.
7. Run relevant lint, type-check, unit, and build commands when available.
8. Report exact commands and results; never claim tests passed if not run.
9. Summarize changed files, assumptions, and follow-up risks.
