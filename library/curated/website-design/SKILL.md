# Website Design

## Workflow
1. Clarify audience, primary user goal, content, constraints, and success criteria.
2. Inspect existing code, brand assets, reference screenshots, and design requirements.
3. Define information architecture and page sections before coding.
4. Specify design tokens: typography, spacing, colors, borders, elevation, and motion.
5. Choose a stack based on constraints; avoid unnecessary dependencies.
6. Build reusable, responsive components with semantic HTML.
7. Check mobile/tablet/desktop layouts, keyboard navigation, focus states, forms, and empty/error/loading states.
8. Review contrast, reduced-motion support, performance, metadata, and maintainability.
9. Report implementation, run steps, tests performed, and uncertainties.

## Quality bar
- Clear hierarchy and consistent spacing.
- No decorative motion that harms usability.
- No fake functionality or invented testimonials.
- Accessible labels and keyboard support.
- Responsive layout rather than desktop-only fixed widths.
