# Cybersecurity

## Scope
Work only on systems the user owns or is explicitly authorized to assess. Keep testing defensive and scoped.

## Workflow
1. Clarify assets, trust boundaries, threat model, authorization, and allowed scope.
2. Prioritize secure configuration, access control, input validation, secrets handling, dependency health, and logging.
3. Explain vulnerabilities with impact, evidence, and safe remediation.
4. Prefer non-destructive checks and test environments.
5. Never expose credentials or include real secrets in reports.
6. Recommend minimal fixes and regression tests.
7. State scope and limitations; do not claim a system is secure based on a limited review.
